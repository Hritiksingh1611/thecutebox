# thecutebox.in — Project README

## ✨ Artisan gifting — Gift With Intent

A boutique e-commerce gifting website built with React + Vite + Tailwind CSS, deployed to GitHub Pages.

### Features
- 🎁 Curated gift catalog (8+ artisan products, search + filter)
- ✨ Build Your Box — 3-step interactive custom gift builder  
- 🧺 Ready Hampers — premium pre-curated boxes
- 🤝 Artisan profiles with maker stories
- 🏢 Corporate gifting with bulk pricing tiers
- 🛒 Cart & Wishlist (Zustand + localStorage persistence)
- 🎯 Gift Finder Quiz (3 questions → perfect gift)
- 📱 Fully responsive, mobile-first

### Tech Stack
React 19 · Vite 6 · Tailwind CSS v3 · React Router v7 · Zustand v5 · Lucide React · GitHub Pages
